# Anshar_UiProgrammer
Task assignment made on Unreal Engine 5.5.4. Created in ~7 days.

The goal was to make simple HUD which consists of Health and Skills Bar (toggling all three slots makes progress bar charged) and Pause Menu - all with animations and transitions implemented.

Implementation uses Common UI to support all kinds of gamepads with keyboard support.

### Controls
| Action  | Keyboard | Gamepad
| ------------- | ------------- | ------------- |
| Open Pause  | Escape |    B/Circle            |
| Interact (Health)  | E  |  A/Cross             |
| Toggle Slot | Arrow Keys | D-Pad |
| Confirm | Enter | Cross
| Back | Escape | B/Circle |
